## 해결하려는 문제

AI 코딩 환경은 빠르게 파편화됩니다. 글로벌 에이전트와 프로젝트 전용
에이전트가 섞이고, 여러 도구에 스킬과 플러그인이 쌓입니다. 같은 역할이
다른 이름으로 반복되면서 무엇이 연결됐고, 중복됐고, 유용하며, 공용으로
승격해도 안전한지 파악하기 어려워집니다.

Agent Observatory는 흩어진 로컬 상태를 설명 가능한 시스템으로 바꿉니다.

~~~mermaid
flowchart LR
  D["발견"] --> N["정규화"]
  N --> C["비교"]
  C --> P["미리보기"]
  P --> A["승인 후 실행"]
  A --> U["안전할 때 되돌리기"]
~~~

## 한눈에 보기

| 영역 | 제공 기능 | 상태 |
|---|---|---|
| **환경 인벤토리** | 표시 안전한 Codex, Claude, 공용 에이전트 메타데이터 탐색 | 사용 가능 |
| **프로젝트 범위** | 전체, 환경별, 개별 프로젝트 화면 전환 | 사용 가능 |
| **에이전트 계층** | 기본 세션, 서브에이전트, 역할, 스킬, 부모 관계 연결 | 사용 가능 |
| **레지스트리** | 유사성 근거 설명과 프로젝트 간 승격 후보 탐지 | 사용 가능 |
| **승격 실행** | 공용 Markdown 또는 Codex TOML 생성 전 대상과 충돌 미리보기 | 사용 가능 |
| **기능 카탈로그** | 스킬, 플러그인, 훅, MCP 서버를 태그와 출처로 검색 | 사용 가능 |
| **관계 그래프** | 반복 역할을 묶고 환경에서 에이전트로 이어지는 관계 시각화 | 사용 가능 |
| **Finance Lab** | 로컬 리서치 목표, 기능, 일정, 예상 비용, 가드레일 구성 | 데모 |

## 워크스페이스

대시보드는 데스크톱 중심의 작업 공간 구조를 사용합니다.

- 접근성 라벨과 툴팁이 있는 아이콘 전용 왼쪽 내비게이션
- 접을 수 있는 환경·프로젝트 보조 사이드바
- 개요, 프로젝트, 레지스트리, 그래프, Finance용 대형 작업 화면
- 한국어·영어 인터페이스
- 44px 내비게이션 영역을 유지하는 반응형 레이아웃

## 핵심 흐름

### 1. 범위를 선택해 관찰

전체 환경에서 시작해 Codex 또는 Claude로 좁힌 다음 하나의 로컬
프로젝트를 선택합니다. 활성 범위에 따라 수치, 활동, 관계, 레지스트리가
함께 변경됩니다.

### 2. 에이전트와 기능 설명

에이전트, 스킬, 플러그인, 훅, MCP 항목에 마우스를 올리거나 키보드로
포커스하면 허용된 메타데이터만 사용한 간단한 설명을 확인할 수 있습니다.

### 3. 중복과 유사성 탐지

레지스트리는 이름, 역할, 태그, 기능, 스킬, MCP 서버, 권한을 비교합니다.
유사도는 숫자만 표시하지 않고 어떤 근거가 점수에 영향을 주었는지 함께
보여줍니다.

### 4. 신중하게 글로벌 승격

한 프로젝트의 에이전트가 여러 프로젝트에 유용하다면 공용 에이전트 또는
Codex 정의로 승격할 계획을 미리 볼 수 있습니다. 실행 전 대상 경로,
형식, 관찰된 스킬, 기존 파일 충돌을 확인합니다.

생성된 정의는 내용 해시가 그대로일 때만 되돌릴 수 있어, 이후 수정된
파일을 실수로 삭제하지 않습니다. 되돌리기 정보는 메모리에 보관되며 현재
데몬 세션 안에서만 사용할 수 있습니다.

## 아키텍처

~~~mermaid
flowchart LR
  C["Codex<br/>~/.codex"] --> D["루프백 데몬<br/>127.0.0.1:4317"]
  L["Claude<br/>~/.claude"] --> D
  A["공용 에이전트<br/>~/.agents"] --> D
  D --> R["마스킹 및 정규화"]
  R --> S["안전한 스냅샷 API"]
  S --> W["React 대시보드<br/>127.0.0.1:4173"]
  W --> Q["전체 / 환경 / 프로젝트 범위"]
~~~

루프백 데몬은 환경마다 다른 로컬 구조를 다음 공통 모델로 정규화합니다.

~~~text
환경
  +-- 프로젝트
      +-- 기본 세션
          +-- 서브에이전트 세션
~~~

Codex 부모 관계는 안전한 `session_meta` 필드에서, Claude 부모 관계는
프로젝트 세션과 중첩된 `subagents` 디렉터리 구조에서 확인합니다.

## 개인정보 보호 경계

탐색과 스냅샷 수집은 기본적으로 읽기 전용이며 클라우드 계정, 텔레메트리
서비스, 모델 API가 필요하지 않습니다. 승인된 Registry 실행은 명시적인 쓰기
예외로, 새 정의만 생성하고 기존 파일은 덮어쓰지 않습니다.

| 대시보드에 반환 | 반환하지 않음 |
|---|---|
| 환경 식별자 | 대화 메시지 또는 프롬프트 |
| 정제된 프로젝트 라벨 | 에이전트 지침 또는 임의 파일 내용 |
| 불투명 세션 식별자 | 명령, 인자, 도구 입력 또는 출력 |
| 부모 세션 관계 | URL, 헤더, 토큰 또는 인증정보 |
| 명시된 역할·스킬 메타데이터 | 환경 변수 값 또는 신뢰 해시 |
| 관찰 시각 | 사용자명 또는 절대 홈 경로 |
| 설치 자산 이름과 상태 | 인증정보가 포함된 설정 값 |

자동화 테스트에는 가짜 비밀값, 사용자명, 절대 경로가 결과에 포함되지
않는지 확인하는 센티널 검사가 포함됩니다.

## 빠른 시작

### 요구 사항

- Node.js 20 이상
- npm 10 이상
- 선택 사항: `~/.codex`, `~/.claude`, `~/.agents`의 로컬 데이터

### 설치

~~~bash
git clone https://github.com/J3vn0/Agent-Observatory.git
cd Agent-Observatory
npm install
~~~

> [!IMPORTANT]
> 모든 npm 명령은 `package.json`이 있는 저장소 루트에서 실행해야 합니다.
> npm이 `Could not read package.json`을 표시한다면 현재 폴더를 먼저
> 확인하세요.

### 실행

터미널 1:

~~~bash
npm run dev:daemon
~~~

터미널 2:

~~~bash
npm run dev:dashboard
~~~

브라우저에서 **http://127.0.0.1:4173**을 엽니다. 로컬 데몬과 연결되면
헤더에 **실시간**이 표시되고, 연결되지 않으면 예시 데이터임을 명확히
표시합니다.

### PowerShell에서 실행 위치 확인

~~~powershell
Get-Location
Test-Path .\package.json
~~~

`Test-Path` 결과가 `True`여야 합니다.

경로 재정의, 상태 확인, 개인정보 보호 세부사항은
[SETUP.md](./SETUP.md)를 참고하세요.

## 선택적 경로 재정의

기본 경로를 사용한다면 `.env` 파일이 필요하지 않습니다.

~~~dotenv
AGENT_OBSERVATORY_CODEX_HOME=
AGENT_OBSERVATORY_CLAUDE_HOME=
AGENT_OBSERVATORY_AGENTS_HOME=
AGENT_OBSERVATORY_PORT=4317
VITE_OBSERVATORY_API=
~~~

## 검증

~~~bash
npm run typecheck
npm test
npm run build
~~~

기본 테스트는 외부 MCP 서버, 금융 데이터 제공자, 모델 API 없이 실행됩니다.

## 설계 원칙

1. **변경하기 전에 관찰합니다.** 설치, 비활성화, 삭제, 승격 전에
   먼저 발견하고 비교합니다.
2. **모든 점수를 설명합니다.** 유사도, 상태, 비용, 추천에는 판단 근거가
   함께 표시되어야 합니다.
3. **실행을 되돌릴 수 있게 합니다.** 대상과 충돌을 미리 보고, 명시적으로
   승인하며, 안전하지 않은 되돌리기는 거부합니다.
4. **데몬을 로컬에 둡니다.** 브라우저에는 무제한 경로나 인증정보 값을
   전달하지 않습니다.
5. **금융 기능은 근거를 우선합니다.** 시장·공시 흐름에는 출처, 관찰 시각,
   최신성, 비용을 표시합니다.

> [!CAUTION]
> Agent Observatory는 투자 자문을 제공하거나 거래를 실행하지 않습니다.
> Finance Lab은 연결되지 않은 제품 데모이며 실시간 데이터·증권사 연동이 아닙니다.
