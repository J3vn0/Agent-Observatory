# 2026-07-26 — Finance Lab demo

## Intent

Add a future Finance expansion plan and make its core interaction testable as a separate dashboard page.

## Decisions

- Personalize the research workflow, not securities or portfolio actions.
- Treat Serenity/X posts as unverified leads.
- Require an official API or licensed source adapter for production monitoring.
- Keep proposal, installation, credentials, monitoring, and scheduling as separate approval steps.
- Enforce visible run/month budgets and staged low-cost processing.

## Implementation

- Created worktree `finance-personalization` on branch `agent/finance-personalization`.
- Used `frontend-design` and `clean-minimal-beige-light-mode` to extend the white editorial dashboard.
- Added an interactive Finance page with questionnaire, source policy, capability adoption, cadence, token estimate, guardrails, and local draft save.
- Added the canonical design plan and [[2026-07-26-finance-personalization-lab]] memory note.
- Delegated finance-safety and dashboard-architecture reviews to specialized subagents.

## Boundary

The demo contains no live X connection, no crawler, no brokerage access, and no personalized security recommendation. `Serenity (@aleabitoreddit)` is displayed as a disconnected demo source.
